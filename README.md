# Diabetes Prediction using Decision Tree

Machine Learning project that predicts diabetes class 
(Diabetic / Non-Diabetic / Predicted-Diabetic) using medical data.

## Dataset
- Source: Mendeley Data
- 1000 patients
- Features: BMI, HbA1c, Cholesterol, Age, etc.

## Steps
1. Data preprocessing
2. Encoding & cleaning
3. Train/Validation/Test split (70/15/15)
4. Decision Tree model
5. Hyperparameter tuning with GridSearchCV
6. Evaluation using confusion matrix & classification report

## Results
Final Test Accuracy: **96%**

## Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn
